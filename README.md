# v1_dev_multiome
This repo contains custom code for the manuscript "[*establishing a continuum of cell types in the visual cortex*](https://www.biorxiv.org/content/10.1101/2025.09.22.677893v1)".

See [here](https://github.com/FangmingXie/SingleCellArchetype) for a demo applying archetypal analysis to V1 L2/3 neurons profiled by snRNA-seq.
